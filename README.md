# Night Lane Rush

A fast-paced HTML5 lane-dodging game that runs in the browser. Switch lanes to avoid obstacles and survive as long as you can to get a high score.

## How to Play
- Use the arrow keys (or tap on mobile) to switch lanes
- Avoid the obstacles
- Score increases the longer you survive

## Tech Stack
HTML5, CSS3, JavaScript

## Run Locally
Download the files and open index.html in your browser.
